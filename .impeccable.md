## Design Context

Taken from the PRD (sections 2, 6 and 10). The PRD wins if they disagree.

### Users
Students aged 6 to 18 taking a 10 minute placement test, in English or Arabic, often on a phone or a family laptop. The sales team reads results in the admin view while talking to parents. The content team previews questions.

### Brand Personality
Warm, clear, capable. The test should feel fair and calm, never like an exam room. Young students get play; older students get respect: real tools, real code.

### Aesthetic Direction
- iSchool brand: blue leads, orange accents, a little gold. Baloo 2 headings, Nunito Sans body, Noto Sans Arabic. Light screens at every age, no dark mode.
- Older students: playful through real-looking code and drag and drop, not cartoons. Code looks like the editor they will use in that grade (PRD 6.5).
- Anti-references: emoji as icons, gradient banners, confetti, cheerleading copy, a shadow on every element.

### Design Principles
1. Real over decorative. A code question looks like a real editor, a block question like real blocks.
2. Fewer things on screen, more space. Answers never get pushed off screen.
3. One interaction language. Drag, or tap then tap, the same everywhere.
4. Never hint right or wrong to the student.
5. Arabic is full RTL; code stays LTR.
